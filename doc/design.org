#+title: Midicaptain for Fractal Devices (especially for FM3)

* Intro
Midicaptain(이하 MC) 자체에서 FM3등 Fractal Device(이하 FM3)를 위한 설정을
지원하고 있으나 FM3와 일체화된 기능을 제공하지 못하고 있다. 단방향  CC/PC
command 위주로 사용하여 FM3를 제어하는 기능을 제공하며 제어자체는 잘 되나, FM3의
상태를 알지못하기 때문에 Scene이 변할 때 effects의 on/off 상태를 받아오지 못해,
현재 effects의 on/off 상태를 모르거나 on/off 상태가 불일치하는 사용상 불편한
점이 있다. 

이 프로젝트는 이러한 상태 불일치 문제를 해결하고 편의 기능을 추가하여 FC6 처럼
FM3와 일체화된 Controller를 만드는 것이 목적이다.

* Usecases
** case1 : MC를 FM3 effects on/off 용도로 사용
MD의 Button A,B,C,D를 Comp1, Drive1, Chorus1, Delay1을 on/off할 수 있게
설정하였다.
Button을 밟으면 해당 effects가 on/off toggle된다. 이때 Button에 할당된 LED 각
3개가 미리 지정한 색상으로 on/off된다.
사용자가 FM3 버튼을 이용하거나 기타 조작으로 scene을 변경하면 변경된 scene의
Comp1, Drive1, Chorus1, Delay1 block 유무 및 on/off 상태를 FM3로부터 받아와
Button A,B,C,D의 on/off 상태를 동기화 한다.

** case2 : MC를 FM3 scene select 용도로 사용
MD Button 1,2를 각각 scene number 7, 8로 바꾸는 용도로 설정하였다.
Button 1을 press하면 FM3의 scene이 scene number 7로 바뀐다.
이 때 Button1은 LED가 on되고 그외 select 용도로 할당된 Button 2의 LED는 off된다.

사용자가 FM3 버튼을 이용하거나 기타 조작으로 scene을 변경하였다.
- scene7로 변경하였다면, Button1 LED on, Button2 LED off 된다.
- scene8로 변경하였다면, Button1 LED off, Button2 LED on 된다.
- scene1~6중 하나로 변경하였다면, Button1, Button2 모두 off된다.

** Button 기능
+ press type :: short press / long press별 제어 기능 할당

** FM3 Control Type별 Button LED 동작 방식
+ 각 버튼마다 3개의 LED가 있으며 각각 제어 가능하다
  - LED1, LED2, LED3
+ short press / long press 동작에 각각 LED 색상을 지정할 수 있다.
+ EFFECT_TOGGLE_ON_COLOR  : 사용자가 직접 LED1, LED2, LED3 색상 설정
+ EFFECT_TOGGLE_OFF_COLOR : int(EFFECT_TOGGLE_ON_COLOR * 0.2)
