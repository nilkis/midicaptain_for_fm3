#+title: Midicaptain for Fractal Devices (especially for FM3)

* Intro
Midicaptain(이하 MC) 자체에서 FM3등 Fractal Device(이하 FM3)를 위한 설정을
지원하고 있으나 FM3와 일체화된 기능을 제공하지 못하고 있다. 단방향  CC/PC
command 위주로 사용하여 FM3를 제어하는 기능을 제공하며 제어자체는 잘 되나, FM3의
상태를 알지못하기 때문에 Scene이 변할 때 effects의 on/off 상태를 받아오지 못해,
현재 effects의 on/off 상태를 모르거나 on/off 상태가 불일치하는 사용상 불편한
점이 있다.

이 프로젝트는 이러한 상태 불일치 문제를 해결하고 편의 기능을 추가하여 FC6 처럼
FM3와 일체화된 Controller를 만드는 것이 목적이다.

* SysEx Protocol
참조: [[Axe-Fx III MIDI for 3rd Party Devices.pdf]] (Revision 1.4)

** 공통 구조
FM3 SysEx 메시지 공통 형식:
#+begin_example
F0 00 01 74 <model_id> <function_id> [data...] <checksum> F7
#+end_example

- Manufacturer ID: =0x00 0x01 0x74= (Fractal Audio Systems)
- Model ID: =0x10= (Axe-Fx III), =0x11= (FM3)
- Checksum: =0xF0 XOR manufacturer_id bytes XOR data bytes=, masked =& 0x7F=
- Query 패턴: 대부분의 SET/GET 명령에서 data를 =0x7F= 로 보내면 현재값 조회

** Command 목록

|        0x0C | SysEx        | SET/GET_SCENE    | 양방향   | Scene 설정/조회 (dd=7F로 query)    | [구현완료] |

** SET/GET_BYPASS (0x0A) 상세
Effect의 bypass 상태를 설정하거나 조회한다.
#+begin_example
F0 00 01 74 11 0A <id_lo> <id_hi> <dd> <checksum> F7
#+end_example
- id_lo, id_hi: effect ID를 7-bit MIDI byte 2개로 표현 (LS first)
  - id_lo = =fx_id % 128=, id_hi = =fx_id // 128=
- dd: =0= = engaged, =1= = bypassed, =0x7F= = query

응답 (query시):
#+begin_example
F0 00 01 74 11 0A <id_lo> <id_hi> <dd> <checksum> F7
#+end_example
- dd: =0= = engaged, =1= = bypassed

** SET/GET_CHANNEL (0x0B) 상세 [구현완료]
Effect의 channel을 설정하거나 조회한다.
#+begin_example
F0 00 01 74 11 0B <id_lo> <id_hi> <dd> <checksum> F7
#+end_example
- id_lo, id_hi: effect ID (LS first)
- dd: channel (=0= ~ =3=), =0x7F= = query

응답 (query시):
#+begin_example
F0 00 01 74 11 0B <id_lo> <id_hi> <dd> <checksum> F7
#+end_example
- dd: 현재 channel (0~3)

** SET/GET_SCENE (0x0C) 상세 [구현완료]
Scene을 설정하거나 조회한다.
#+begin_example
F0 00 01 74 11 0C <dd> <checksum> F7
#+end_example
- dd: scene number, =0x7F= = query

응답 (query시):
#+begin_example
F0 00 01 74 11 0C <dd> <checksum> F7
#+end_example
- dd: 현재 scene number

** QUERY_PATCH_NAME (0x0D) 상세 [구현완료]
Preset(Patch) name을 조회한다.
#+begin_example
F0 00 01 74 11 0D <dd> <dd> <checksum> F7
#+end_example
- dd dd: preset number (7-bit MIDI bytes, LS first). 현재 preset 조회시 =0x7F 0x7F=

응답:
#+begin_example
F0 00 01 74 11 0D <nn> <nn> <name 32 bytes> <checksum> F7
#+end_example
- nn nn: preset number (7-bit MIDI bytes, LS first)
- name: 32 characters

** QUERY_SCENE_NAME (0x0E) 상세 [구현완료]
Scene name을 조회한다.
#+begin_example
F0 00 01 74 11 0E <dd> <checksum> F7
#+end_example
- dd: scene number. 현재 scene 조회시 =0x7F=

응답:
#+begin_example
F0 00 01 74 11 0E <nn> <name 32 bytes> <checksum> F7
#+end_example
- nn: scene number
- name: 32 characters

** TAP_TEMPO (0x10) 상세
Tempo 버튼을 원격으로 탭한다.
#+begin_example
F0 00 01 74 11 10 <checksum> F7
#+end_example

Push data (FM3 → MC, Send Realtime Sysex = On 설정시):
#+begin_example
F0 00 01 74 11 10 F7
#+end_example
- tempo downbeat마다 전송됨
- checksum 없음 (메시지 길이 최소화)

** TUNER (0x11) 상세 [구현완료]
Tuner on/off 제어:
#+begin_example
F0 00 01 74 11 11 <dd> <checksum> F7
#+end_example
- dd: =0= = off, =1= = on

Push data (FM3 → MC, Tuner 활성화시): [구현완료]
#+begin_example
F0 00 01 74 11 11 <nn> <ss> <cc> F7
#+end_example
- nn: note (0~11)
- ss: string (0~5, 0 = low E)
- cc: cents (offset binary, 63 = 0, 62 = -1, 64 = +1)
- checksum 없음

** STATUS_DUMP (0x13) 상세
현재 preset의 전체 effect 상태를 일괄 조회한다.

요청:
#+begin_example
F0 00 01 74 11 13 <checksum> F7
#+end_example

응답 (FM3 → MC):
#+begin_example
F0 00 01 74 11 13 <packet0> <packet1> ... <packetN> <checksum> F7
#+end_example
각 packet은 3바이트 (id_lo, id_hi, dd):
- id_lo, id_hi: effect ID (14-bit, 7-bit MIDI bytes 2개, LS first)
- dd:
  - bit 0: bypass state (=0= = engaged, =1= = bypassed)
  - bit 3~1: channel (0~7, 현재 최대 channel 수는 3)
  - bit 6~4: 해당 effect가 지원하는 channel 수 (0~7)

** SET/GET_TEMPO (0x14) 상세 [구현완료]
Tempo BPM을 설정하거나 조회한다.
#+begin_example
F0 00 01 74 11 14 <dd> <dd> <checksum> F7
#+end_example
- dd dd: tempo 값 (7-bit MIDI bytes 2개, LS first). 조회시 =0x7F 0x7F=

응답 (query시):
#+begin_example
F0 00 01 74 11 14 <dd> <dd> <checksum> F7
#+end_example

** PATCH_INC, PATCH_DEC 상세 [구현완료]
SysEx로 Patch를 inc/dec하는 명령은 없다.
CC Command로 대신한다.
- PATCH_INC: CC#41, value=127
- PATCH_DEC: CC#42, value=127

* Usecases
** case1 : MC를 FM3 effects on/off 용도로 사용
MC의 Button A,B,C,D를 Comp1, Drive1, Chorus1, Delay1을 on/off할 수 있게
설정하였다.
Button을 밟으면 해당 effects가 on/off toggle된다. 이때 Button에 할당된 LED 각
3개가 미리 지정한 색상으로 on/off된다.
사용자가 FM3 버튼을 이용하거나 기타 조작으로 scene을 변경하면 변경된 scene의
Comp1, Drive1, Chorus1, Delay1 block 유무 및 on/off 상태를 FM3로부터 받아와
Button A,B,C,D의 on/off 상태를 동기화 한다.

** case2 : MC를 FM3 scene select 용도로 사용
MC Button 1,2를 각각 scene number 7, 8로 바꾸는 용도로 설정하였다.
Button 1을 press하면 FM3의 scene이 scene number 7로 바뀐다.
이 때 Button1은 LED가 on되고 그외 scene select 용도로 할당된 Button 2의 LED는 off된다.

사용자가 FM3 버튼을 이용하거나 기타 조작으로 scene을 변경하였다.
- scene7로 변경하였다면, Button1 LED on, Button2 LED off 된다.
- scene8로 변경하였다면, Button1 LED off, Button2 LED on 된다.
- scene1~6중 하나로 변경하였다면, Button1, Button2 모두 off된다.

** case3 : 전원 스위치 ON
+ Display에 Welcome Message를 보여준다. [구현완료]
+ 10개의 Button LED로 Welcome light를 보여준다. [구현완료]
+ Welcome message/light가 끝나면 FM3 현재 Tap Tempo BPM/preset name/scene name 을
  화면에 계속 보여준다. [구현완료]

** case4 : Tuner/Tap Tempo
+ 10개 버튼 중 Down Switch에 Tuner / Tap Tempo 제어 기능을 할당하였다.
+ 버튼을 long press(500ms) 하면 떼는 순간 FM3 화면에 Tuner가 디스플레이 된다. [구현완료]
  + long press는 항상 떼는 순간 제어 기능을 활성화하게 한다.
+ 다시 버튼을 long press하면  FM3 tuner가 사라진다. [구현완료]
+ 이 버튼은 현재 FM3에 설정된 BPM에 맞춰 Blink한다. [구현완료]
+ 이 버튼을 짧게 계속 누르면 누르는 간격에 맞춰 FM3 Tap Tempo BPM이 변경된다. [구현완료]
+ 이 때 Midicaptain display에는 현재 바뀌는 BPM 값을 보여준다. [구현완료]
+ Tuner 활성화시 FM3로부터 push data (note, string, cents)를 수신하여
  Tuner 전용 화면에 표시한다. [구현완료]

* 기능 정의
** Button에 할당 가능한 FM3 제어(Control) 기능
+ Type A [구현완료]
  - effect toggle [구현완료]
  - scene select [구현완료: scene select LED 상호배타 동작 포함]
+ Type B [구현완료]
  - channel toggle [구현완료]
  - channel rotation [구현완료]
+ Type C [구현완료]
  - preset increment [구현완료: CC#41]
  - preset decrement [구현완료: CC#42]
  - tuner on/off [구현완료]
+ Type D [구현완료]
  - tap tempo set

channel toggle: 2채널(A/B) 간 전환. 현재 channel이 0이면 1로, 1이면 0으로.
channel rotation: 전체 채널 순환. (현재 channel + 1) % 지원 channel 수.

** FM3 상태 동기화 [구현완료: polling 방식]
- Button에 할당된 제어의 상태를 FM3와 동기화한다.
- 예를들어, Button1에 Drive1 on/off를 할당하였을 때, FM3의 scene이 변경되었을
   때 Drive1의 on/off 상태를 FM3로부터 읽어와 on/off 상태를 동기화 한다.
- 구현: round-robin polling 방식
  - STATUS_DUMP: 매 0.15초
  - GET_SCENE: 매 3번째 polling (≈0.45초)
  - QUERY_PATCH_NAME: 매 13번째 polling (≈2초)
  - QUERY_SCENE_NAME: 매 13번째 polling, 오프셋 7 (≈2초)
- STATUS_DUMP 응답 처리시 변경된 effect만 LED 업데이트 (성능 최적화)

** 편집 기능 [구현완료]

    - Long Type / Long Target

    - Back (Level 1로 복귀)
  - encoder 회전으로 메뉴 항목 이동, 클릭으로 값 편집 진입/종료
  - 값 편집 중 encoder 회전으로 값 변경

** Button press 지원 종류 [구현완료]
+ press type :: short press / long press별 제어 기능 할당
+ press 시각을 기록하고, release 시 duration 계산
  - duration >= 500ms → long press
  - duration < 500ms → short press
+ tap tempo는 press 즉시 발동 (release 대기 없이)

** 제어 기능 할당 조합
하나의 Button short press/long press에 FM3 제어 기능 중 임의 조합이 할당
가능하나 다음과 같은 제한이 있다.

+ channel toggle / channel rotation :: short press에 effect toggle 기능이
  할당되었을 때, long press에 할당 가능하며 해당 effect의 channel
  toggle/rotation만 가능하다.
+ tap tempo set :: short press에만 할당 가능하다.

** Button LED 기능 [구현완료]
- Button에 할당된 제어 기능의 상태를 LED를 이용하여 사용자에게 시각화해준다.
- 예를 들어,
  - Button 1에 Drive1이 할당되었을 때, Drive1이 on되면 Button1 LED를 on하고
     Drive1이 off되면 Button1 LED를 off한다. [구현완료]
  - Button 1에 Drive1 Channel rotation이 할당되었을 때, 현재 선택된 channel에
     따라 Drive1 기본 색상을 변경한다. (channel A - green, channel B - yellow,
     channel C - orange, channel D - red) [구현완료]
  - Button1,2,3,4에 각각 scene select 1,2,3,4가 할당되었을 때, scene1이
     select되면 Button1의 LED가 켜지고 Button2,3,4는 꺼진다. 나머지 Button의
     LED는 영향받지 않는다. [구현완료]

*** LED 구조
+ 각 Button마다 3개의 LED가 있으며 각각 제어 가능하다 [구현완료]
  - LED1, LED2, LED3
  - LED1, LED2, LED3는 삼각형 모양으로 Button을 둘러싸고 있다.
  - 삼각형 왼쪽 변부터 시계방향으로 LED1, LED2, LED3이다.

*** LED 색상 지정
Activation 색상만 지정한다.
Deactivation 색상은 Activation색상의 밝기를 0.02로 조정한 값으로 자동 할당한다.
+ ON_COLOR  : 사용자가 직접 LED1, LED2, LED3 색상 설정
+ OFF_COLOR : int(ON_COLOR * 0.02)

*** Button 제어 기능 조합 별 LED 색상 동작 [구현완료]
+ 기본 :: 할당된 제어기능 상태에 따라 ON_COLOR 또는 OFF_COLOR 색상을 표시한다. [구현완료]
+ Tap Tempo Set :: 현재 Tap Tempo BPM에 맞춰 Blink한다. [구현완료]
+ Tuner, preset increment, preset decrement :: press할 때 일시적으로 on되었다가 꺼진다. [구현완료]
+ Scene select :: scene select 제어 기능이 할당된 Button은 현재 선택된 scene에
  해당하는 LED만 ON되고 나머지는 모두 OFF된다. [구현완료]

그외 제어기능 조합에 따라 다음과 같이 동작한다. [구현완료]

*** 화면 레이아웃
1. page number 및 current BPM
   - page number는 추후 구현을 위해 넣음. 현재는 고정 #1
2. Patch Name 표시
3. Scene Name 표시
   - 현재 "Scene: Jumped" 이런 형태로 앞에 "Scene:"이 있는데 제거할 것
4. 가장 최근 Button press에 의해 제어된 기능 표시
   - 기능(예제에서는 DRIVE1) 과 상태(ON/OFF)를 각각 line에 나누어 표시

정보의 중요도 순으로 폰트 크기를 달리한다.
정보의 중요도 순: (4) -> (2), (3) -> (1)
   
#+begin_example

(2) |           Patch_Name
(3) |           Scene_Name
