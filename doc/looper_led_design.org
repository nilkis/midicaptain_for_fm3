#+title: Looper LED Design
#+options: toc:2

* 개요
Fractal Looper 블록(SysEx 0x0F)을 MIDI Captain 풋스위치에 매핑할 때의 LED 표현 설계.

핵심: *누르는 버튼(0~5)과 돌아오는 상태 비트(0~5)가 1:1이 아니다.*
- Overdub은 버튼이 없고(Record가 겸함) 상태 비트만 있음
- Undo는 버튼만 있고 상태 비트가 없음

* Looper 동작 요약
| 버튼(송신값) | 동작                                                                                   | 성격                    |
|--------------+----------------------------------------------------------------------------------------+-------------------------|
| Record (0)   | 첫 누름: 녹음 시작 → 다시 누름: 루프 확정 + 자동 Play. 재생 중 누름: Overdub 시작/종료 | 상태 순환               |
| Play (1)     | 재생 시작/정지 토글. Record 중 누르면 루프 확정 + 재생                                 | 토글                    |
| Undo (2)     | 마지막 Overdub 레이어 취소. 한 번 더 누르면 Redo                                       | 순간 동작 (상태 없음)   |
| Once (3)     | 루프를 1회만 재생하고 정지 (반복 안 함)                                                | 재생 모드 토글          |
| Reverse (4)  | 루프 역방향 재생                                                                       | 재생 모드 토글          |
| Half-speed (5) | 반속 재생 (1옥타브 다운)                                                             | 재생 모드 토글          |

** 재생 모드(Once/Reverse/Half)와 Record의 관계
- 첫 Record(루프 만들기)에는 세 모드가 영향 없음
- *Overdub에는 Reverse/Half-speed가 영향*: 재생 중 덧녹음이므로 재생 모드가 결과물에 박힘
  - Reverse 중 Overdub → 정방향 재생 시 그 레이어가 거꾸로 들림
  - Half-speed 중 Overdub → 정속 재생 시 그 레이어가 2배속·1옥타브 위로 들림
- Once는 재생이 끝나 정지되어도 *모드 자체는 유지*됨 (bit3 = 1 그대로).
  즉 "Once ON + Play OFF"는 정상 상태이므로 Play LED가 꺼져도 Once LED는 켜져 있어야 함

* 응답 상태 비트 (FM3 → MIDI Captain, SysEx 0x0F 응답)
| bit | 의미        | 관련 버튼        |
|-----+-------------+------------------|
|   0 | Recording   | Record           |
|   1 | Playing     | Play             |
|   2 | Overdubbing | Record (겸용)    |
|   3 | Once 모드   | Once             |
|   4 | Reverse 모드 | Reverse         |
|   5 | Half-speed 모드 | Half-speed   |

* LED 설계
** 버튼별 상태 표현
| 버튼       | 대기(OFF)      | 활성(ON)                                              | 참조 비트   | 비고                                        |
|------------+----------------+-------------------------------------------------------+-------------+---------------------------------------------|
| Record     | 어두운 빨강    | Recording: *빨강 켜짐* / Overdubbing: *주황*           | bit0 / bit2 | 한 버튼이 3상태(대기·녹음·오버덥) 표현       |
| Play       | 어두운 초록    | Playing: *초록*                                        | bit1        | (선택) 녹음 중엔 "누르면 확정" 의미로 깜빡임 |
| Undo       | 어두운 흰색    | Press 순간에만 흰색 점등 후 복귀 (tap 타입 공통 규칙)   | 없음        | 상시 점등 금지 — "항상 활성"으로 오해됨      |
| Once       | 어두운 시안    | *시안*                                                 | bit3        | 단순 토글                                   |
| Reverse    | 어두운 파랑    | *파랑*                                                 | bit4        | 단순 토글                                   |
| Half-speed | 어두운 보라    | *보라*                                                 | bit5        | 단순 토글                                   |

** 색상 체계 원칙
1. *전송 상태 계열(따뜻한 색)* — Record 빨강 / Overdub 주황 / Play 초록.
   Fractal FM3 looper 화면 및 FC 컨트롤러 LED 관례와 일치 → 사용자에게 직관적
2. *재생 모드 계열(차가운 색)* — Once 시안 / Reverse 파랑 / Half-speed 보라.
   세 개를 한 계열로 묶어 전송 상태와 시각적으로 분리. 서로 인접 색상이라 "같은 종류의 모드"로 읽힘
3. *Undo는 무채색(흰색)* — 상태가 없는 순간 동작임을 색으로도 구분
4. 노랑은 사용하지 않음 — 빨강/주황과 붙어 있어 Overdub과 혼동됨

** 기본 색상 값 (RGB)
| 버튼       | ON 색상          | 값              |
|------------+------------------+-----------------|
| Record     | 빨강             | (255, 0, 0)     |
| Record(Overdub) | 주황        | (255, 100, 0)   |
| Play       | 초록             | (0, 255, 0)     |
| Undo       | 흰색             | (200, 200, 200) |
| Once       | 시안             | (0, 220, 220)   |
| Reverse    | 파랑             | (0, 80, 255)    |
| Half-speed | 보라             | (150, 0, 255)   |
| LOOPER1 블록 on/off | 마젠타  | (255, 0, 150)   |

OFF(대기) 색은 기존 규칙대로 ON 색 × =OFF_W= (0.02) 로 어둡게 표시.

** (선택) 루프 유무 표시
상태 비트만으로는 "녹음된 루프가 있는데 정지 상태"(bit1=0)를 직접 알 수 없음.
기기 쪽에서 Recording→Playing 전이를 한 번 기억해 두면 Play 버튼을
"정지 but 루프 있음"으로 중간 밝기 표시 가능. 프리셋 변경 시 리셋.

* 구현 메모
- 현재 =LOOPER_LED_MASKS = (0x05, 0x02, 0x00, 0x08, 0x10, 0x20)= 는 Record를 bit0|bit2 단일 마스크로 처리하여
  Recording/Overdubbing을 같은 색으로 표시함 → *Overdub 별도 색*을 위해 상태별 색 테이블로 확장 필요
- Undo(mask 0)는 현재 "항상 점등"으로 구현되어 있음 → *대기색 + 누를 때 순간 점등*으로 변경 필요
- 프리셋에 Looper 블록이 없으면 looper 명령이 무시됨. LOOPER1 블록 LED(fx_states 부재 → 완전 소등)로 사용자에게 알림
- Looper 상태 폴링은 looper 버튼이 있는 페이지에서만 수행 (기존 로직 유지)
