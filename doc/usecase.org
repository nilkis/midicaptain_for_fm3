* 스위치 동작 및 기능 조합
** 지원하는 스위치 동작
+ short press
+ long press : 설정한 시간 만큼 press를 유지하고 떼는 순간 동작
  - 설정 화면에서 long_press_duration 값 설정. default: 500ms
** 기능 조합
short press / long press에 각각 FM3 제어 기능을 할당할 수 있다.
하나의 스위치에 할당 가능한 조합은 다음과 같다. long/short 순서에 관계없다.
+ effect on off / effect on off
+ effect on off / scene select
+ effect on off / effect channel select
+ tuner, tap tempo, preset increment, preset decrement는 모든 기능과 조합
  가능하다.
  - tap tempo는 특성상 short press에만 할당 가능

지원하지 않는 조합은 다음과 같다
+ effect channel select / effect channel select

* 스위치 LED 색상
+ 각 스위치에는 스위치 상태를 표현하는 LED가 있다.
+ LED는 다음 3가지 상태가 있다.
  - disabled
  - on
  - off
  - tap

+ LED 색상 지정
  - 색상은 "on" 상태의 색상만 지정한다.
  - "off" 상태 색상: "on"상태 색상의 밝기를 30%로 줄인 색상이다.
    - "off" 상태의 색상 밝기는 사용자가 조절할 수 있다.(default 30%)
  - disabled 상태의 색상: "on"상태 색상의 밝기를 0%로 줄인 색상이다.
  - tap 상태의 색상: "on" 상태의 색상이 깜빡인다(blink).

** short/long press에 2개의 기능이 할당된 경우 색상 조절
*** effect1/effect2
+ 3개의 LED(왼쪽부터 시계방향 1,2,3)를 이용하여 2개의 effect가 할당되었음을 나타낸다.
+ led1 : short press 색상
+ led3 : long press 색상
+ led2 : 두 색상의 평균색상
*** effect/channel
+ channel1,2,3,4에 각각 색상을 할당할 수 있다.
+ channel 선택에 따라 effect 색상이 달라진다.
*** effect/scene
+ effect1/effect2 조합과 동일하게 작동
*** preset increment, preset decrement, tuner,
+ effect1/effect2 조합과 동일하게 작동하되,
+ preset increment, preset decrement, tunner가 tap되었을 때 해당 led가 1회 깜빡인다.
*** tap tempo
+ effect1/effect2 조합과 동일하게 작동하되,
+ tap tempo 주기에 맞춰 해당 led가 깜빡인다.

* Tuner/Tap Tempo
+ 10개 버튼 중 Down Switch에 Tuner / Tap Tempo 기능을 할당하였다.
+ 버튼을 long press(500ms) 하면 떼는 순간 FM3 화면에 Tuner가 디스플레이 된다.
  + long press는 항상 떼는 순간 기능을 활성화하게 한다.
+ 다시 버튼을 long press하면  FM3 tuner가 사라진다.
+ 이 버튼은 현재 FM3에 설정된 BPM에 맞춰 Blink한다.
+ 이 버튼을 짧게 계속 누르면 누르는 간격에 맞춰 FM3 Tap Tempo BPM이 변경된다.
+ 이 때 Midicaptain display에는 현재 바뀌는 BPM 값을 보여준다.

* Scene Select
** 버튼 기능 할당
+ Button 1, 2, 3, 4 에 다음과 같이 기능을 할당하였다.
  |-------------+---------+---------+---------+---------|
  | Button      | 1       | 2       | 3       | 4       |
  |-------------+---------+---------+---------+---------|
  | short press | scene 1 | scene 2 | scene 3 | scene 4 |
  |-------------+---------+---------+---------+---------|
  | long press  | scene 5 | scene 6 | scene 7 | scene 8 |
  |-            |         |         |         |         |

+ Button A, B, C, D LED 에 다음과 같이 색상을 할당하였다.
  |-------------+-------+-------+-------+-------|
  | Button      | A     | B     | C     | D     |
  |-------------+-------+-------+-------+-------|
  | short press | red   | red   | red   | red   |
  |-------------+-------+-------+-------+-------|
  | long press  | green | green | green | green |
  |-------------+-------+-------+-------+-------|

** 버튼 동작 예시 1
1. Button 1을 short press하면 Button LED 1이 "on" 색상으로 바뀐다. 나머지 2, 3, 4,
  LED는 "off"색상으로 바뀐다..
   + 이 때 Button 1, 2, 3, 4외의 다른 버튼의 색상은 영향받지 않는다. 
2. FM3의 scene이 scene 1로 변경된다.
3. Midicaptain display의 scene 이름이 변경된다.

** 버튼 동작 예시 2
1. Button 3을 long press하면 Button LED 3이 "on" 색상으로 바뀐다. 나머지 1, 2, 4
   LED 는 "off"상태로 바뀐다.
   + 이 때 Button 1, 2, 3, 4외의 다른 버튼의 색상은 영향받지 않는다. 
2. FM3의 scene이 scene 7로 변경된다.
3. Midicaptain display의 scene 이름이 변경된다.
