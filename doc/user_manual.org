#+options: toc:3

/English | [[file:user_manual.ko.org][한국어]]/

For installation see the [[file:../README.org][README]]. This document covers *how to use* the firmware once installed.

* 1. Overview
Turns the MIDI Captain (10-switch) into a bidirectional controller for the Fractal FM3.
The FM3's state (effect on/off, channels, scene, preset/scene names, BPM, looper) is read over
SysEx and reflected on the LEDs and display in real time.

** Controls
| Control              | Role                                                              |
|----------------------+-------------------------------------------------------------------|
| 10 footswitches      | each has a Press (short) and a Hold (long) action                  |
| Rotary wheel — turn  | switch pages (in Edit Mode: move cursor / change value)             |
| Rotary wheel — click | Edit Mode: select / confirm                                        |
| Rotary wheel — hold  | enter Edit Mode / go back one level / (on MAIN) save and exit       |
| Display (240x240)    | status and Edit Mode menus                                         |

** Switch layout
|---+---+---+---+----|
| 1 | 2 | 3 | 4 | UP |
|---+---+---+---+----|
| A | B | C | D | DN |
|---+---+---+---+----|

* 2. Screen (Normal Mode)
|-------------------------------|
| P2 FX               BPM:120   |  ← current page number/name, FM3 tempo
|-------------------------------|
|         Preset Name           |  ← FM3 preset name (auto-shrinks past 13 chars, up to 20)
|         Scene Name            |  ← current scene name
|                               |
|          DRIVE1               |  ← last action (shown for 1.5 s)
|            ON                 |
|-------------------------------|

- Pressing a switch briefly shows the action at the bottom (e.g. =DRIVE1 / ON=, =SCENE / 3=, =PAGE 2 / FX=)
- When the tuner is on the screen switches to TUNER (note/cents shown if FM3 =Send Realtime SysEx= is ON;
  otherwise a hint is shown — look at the FM3 screen)

* 3. Pages
A page is a set of functions for the 10 switches. There are 8 pages; turn the rotary wheel to switch.
You can also assign =page_inc= / =page_dec= to a switch Hold to change pages by foot (default: Up/Dn Hold).

** Start page
Set with =StartPg= in Global Settings.
- =Last= (default): boot into the page you were last using (auto-saved 3 s after switching)
- =P1= ~ =P8=: always boot into that page (predictable for live use)

* 4. Switch functions
Each switch has separate Press and Hold actions.

| Function          | Action                                          | LED                                        |
|-------------------+-------------------------------------------------+--------------------------------------------|
| effect            | toggle effect block on/off                       | on=bright, off=dim, block absent=off        |
| effect + Rotate   | (Hold) cycle channel A→B→C→D                     | current channel's color                    |
| channel_select    | set a specific channel of an effect (e.g. AMP1 B) | bright if current channel, else dim       |
| scene             | select scene 1~8                                 | bright if current scene                    |
| preset_inc / dec  | preset +1 / -1                                   | dim; flashes bright when pressed           |
| page_inc / dec    | page +1 / -1                                     | dim; flashes bright when pressed           |
| tap_tempo         | tap tempo (fires on press)                       | blinks with FM3 tempo                      |
| tuner             | tuner on/off toggle                              | bright when on                             |
| looper            | Record/Play/Undo/Once/Reverse/Half-speed         | see below                                  |
| none              | nothing                                          | off                                        |

** LED color rules
- Each action gets one of 12 palette colors (same as FM3): Red, Orange, Yellow, Yellow-Green, Green, Teal, Cyan, Blue, Purple, Pink, White, Off
- The 3 LEDs of a switch can be given different colors
- The *Press* action's color drives the LED. Hold is shown on screen only — except when both Press and Hold are state-type (scene/effect/…) and only the Hold one is active: then the Hold color is shown (e.g. Press=scene 1 red, Hold=scene 2 green → green while scene 2 is active)
- active (on) = the color, inactive (off) = the same color, very dim

** Looper LEDs
| Button        | LED                                                                          |
|---------------+------------------------------------------------------------------------------|
| Record        | recording = color (default red), overdubbing = 2nd color (default orange), idle = dim |
| Play          | bright while playing                                                         |
| Undo          | dim; flashes when pressed                                                    |
| Once/Rev/Half | bright when the mode is ON                                                   |
Looper state stays in sync even when operated on the FM3. If the preset has no Looper block, commands are ignored.

** Tap tempo special case
Tap tempo fires the moment you press, so the same switch's Hold can carry another function (e.g. Tuner).

* 5. Hold detection
Adjust in Global Settings.
- =HoldTime=: threshold between Press and Hold, 0.3~2.0 s (default 0.5 s)
- =HoldAt=:
  - =Release= (default): decided when you lift your foot — Hold if held longer than HoldTime
  - =Timeout=: Hold fires the moment HoldTime elapses while pressed; releasing does nothing more.
    Good for "press-and-hold to engage" feel, e.g. Tuner

* 6. Edit Mode — configuring switches and settings
*Press and hold the rotary wheel for 1 s+* to enter. Everything is edited on the device and saved on exit.

** Basic controls
| Control     | Action                                                              |
|-------------+---------------------------------------------------------------------|
| turn        | move cursor / (while editing) change value                          |
| click       | select/enter / (while editing) confirm or next step                 |
| hold        | back one level. While editing a value: end editing only. On MAIN: save & exit |
| footswitch  | *shortcut*: press → jump to that switch's Press editor, hold → its Hold editor (current page) |
| Up + Dn together ≥ 1 s | save & exit Edit Mode from anywhere                             |

** Screen structure
#+begin_example
MAIN
 ├─ Switch  P2 FX      → click → turn to pick page → click → Switch table
 │    ├─ (header) P2 FX → click → edit page name
 │    └─ 1 ~ Dn        → click → Press / Hold → parameter editor
 ├─ Copy Page          → click → turn to pick destination → click = copy (source = page in the Switch row)
 ├─ Global Settings    → HoldTime / HoldAt / StartPg
 └─ Exit               → save & exit
#+end_example

** Switch table
#+begin_example
 P2 FX     Press Hold
 ────────────────────
>1  CHORUS1   -
 2  PHASER1   -
 3  FLANGER1  -
 4  TapTmp    Tuner
 Up Preset+   Page+
 A  COMP1     -
 B  DRIVE1    Rot
 C  PARAEQ1   -
 D  DELAY1    Rot
 Dn Preset-   Page-
#+end_example
- Press/Hold summary of all 10 switches at a glance. =Rot= = channel-rotation sub-function
- The real LED of the switch under the cursor previews live (when editing the current page)
- Put the cursor on the header row and click to *edit the page name*

** Editing the page name
Click header → =*P2 [F]X    = (yellow, [ ] = current slot)
- turn = change character (space → A~Z → 0~9 → =- _ + . /=)
- click = next slot; clicking on the 6th slot confirms
- hold = confirm immediately
- Max 6 chars. All spaces → default name like =P2=

** Copy Page
Copies one page's switches and name onto another — handy for building a USER page from an existing one.
1. On MAIN, pick the *source* page in the =Switch= row (click → turn → click back out, or just turn while editing)
2. Move to =Copy Page=, click → =*Copy P2->P6 USER2= (turn = destination), click = copy
Long-press cancels. Copying onto the current page takes effect immediately.

** Parameter editor (Press / Hold)
Switch → choose Press or Hold → item table
| Item    | Description                                                                          |
|---------+--------------------------------------------------------------------------------------|
| Type    | function type (effect / channel_select / scene / looper / tap_tempo / tuner / preset_inc / preset_dec / page_inc / page_dec / none) |
| Target  | effect name, scene number, looper button …                                           |
| Chan    | (channel_select) channel A~D                                                         |
| Color   | LED color (see below)                                                                |
| Rotate  | (effect, Press only) channel-rotation sub-function ON/OFF                            |
| Chans   | (Rotate ON) which channels to include in the rotation                                |
| Col.A~D | (Rotate ON) color per channel                                                        |
| Col.OD  | (looper Record) overdub color                                                        |

Regular items: click → edit (=*=) → turn to change → click to confirm

*** Editing Color
Color items are shown as *swatches* instead of text, and the switch's real LED lights up with that color.
- click → start editing (target ALL = all 3 LEDs)
- turn = cycle palette colors
- click = cycle target ALL → L1 → L2 → L3 → *click = done*
  Turning while on L1~L3 changes only that LED (3 swatches shown, the one being edited has a white frame)
- hold = done immediately

*** Editing Chans (when Rotate is ON)
=Chans  A B C D= — channels included in the rotation; excluded ones show as =.=
- click → start editing =[A]B C D OK=
- turn = move cursor (A → B → C → D → OK)
- click = include/exclude that channel. Click on =OK= = done
- At least one channel is always kept

** Global Settings
| Item     | Value                       |
|----------+-----------------------------|
| HoldTime | 0.3 ~ 2.0 s (0.1 steps)      |
| HoldAt   | Release / Timeout           |
| StartPg  | Last / P1 ~ P8              |
Click → edit → turn → click to confirm. Hold to return to MAIN.

** Saving
- Choose Exit, or hold on MAIN → saved to =config.json=, back to Normal Mode
- Even if you edited another page you return to the current page
- In USB-drive mode (booted with Switch 1 held) the filesystem is read-only and nothing is saved.
  Edit after a normal boot.

* 7. FM3-side settings
- Two MIDI cables, both directions (see README)
- =SETUP > MIDI/Remote=: make sure MIDI OUT is not set to THRU
- To see tuner note/cents on the MIDI Captain, set =Send Realtime SysEx= ON

* 8. Troubleshooting
| Symptom                                    | Check                                                              |
|--------------------------------------------+--------------------------------------------------------------------|
| LEDs/names don't follow the FM3            | MIDI IN cable (FM3 OUT → MIDI Captain IN), FM3 MIDI OUT mode        |
| An effect's LED is completely off          | that block isn't in the current preset (normal)                    |
| Looper buttons don't respond               | preset has no Looper block — check the =LOOPER1= LED on P4          |
| Tuner screen shows no note/cents           | turn on FM3 =Send Realtime SysEx=                                   |
| Edit Mode changes aren't saved             | booted in USB-drive mode → reboot normally                          |
| Settings reset on boot                     | an old-format config was detected and replaced with defaults (no migration by design) |
| Settings never save; no =config.json= after normal boot | filesystem likely corrupted — reformat with =storage.erase_filesystem()= in the REPL and reinstall (see README troubleshooting) |
| Want the stock firmware back               | restore the backup per the README install section                  |
