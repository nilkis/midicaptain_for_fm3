CircuitPython에 포함되지 않은 python package는
[[https://github.com/adafruit/Adafruit_CircuitPython_Bundle/releases/download/20231003/adafruit-circuitpython-bundle-7.x-mpy-20231003.zip][CircuitPython library bundle]] 에서 추출하여 MidiCaptain lib directory에 복사한다
